# Mini-VC 和 scGPT 迁移结果分析

本分析使用已有的五折测试指标、保存预测、训练日志和模型实现，没有重新训练或选择新参数。
重点是解释这套设置下的结果。结构上的可能原因与经过数据核对的现象分别说明，
没有做过的消融不作为已证实的结论。

## 1. 先区分哪些指标更差

131 个未见双基因组合上的条件宏平均：

| 模型 | 响应 Pearson ↑ | 全基因 MSE ↓ | 真实 Top-100 响应基因 MSE ↓ | 其余 1,900 基因 MSE ↓ |
|---|---:|---:|---:|---:|
| Ridge | 0.896344 | 0.002015 | 0.018343 | 0.001156 |
| MLP | 0.891277 | 0.001982 | 0.018697 | 0.001103 |
| Mini-VC | 0.883719 | 0.001935 | 0.018890 | 0.001043 |
| scGPT frozen | 0.881610 | 0.002111 | 0.018033 | 0.001273 |
| scGPT finetuned | 0.881726 | 0.002068 | 0.017969 | 0.001231 |

“真实 Top-100”按各条件的真实 delta 绝对幅度排序，不是显著性检验筛选。
其余基因也可能有响应，只是没有进入该条件的前 100。最后一列按
`(2000 × mse_all − 100 × mse_de) / 1900` 分解得到，各列都是相同条件的宏平均。

Mini-VC 的全基因 MSE 最低，但响应相关性和 Top-100 恢复率较弱。
它在其余 1,900 个基因上的平均误差更小，在响应最大的 100 个基因上却更大。
因此，整体误差降低不代表关键响应预测同步改善。
scGPT 的情况又有所不同：真实 Top-100 上的 MSE 比 Ridge 更低，
但其余基因的误差、全基因 MSE 和响应相关性较弱。两个模型并不是以相同方式落后。

逐条件比较也不是 Ridge 全部获胜。Mini-VC 在 131 个条件中有 51 个 Pearson 高于 Ridge，
72 个全基因 MSE 更低；微调 scGPT 分别有 47 个和 54 个。
Mini-VC − Ridge 的平均 Pearson 差值为 −0.012625，条件配对 bootstrap 区间为
[−0.023308, −0.002466]。区间描述本数据集中的条件差异，不是独立外部人群检验。

数值来源：[指标分解](../results/model_diagnostics/metric_tradeoffs.csv)、
[逐条件配对比较](../results/model_diagnostics/paired_vs_ridge.csv)。

## 2. Ridge 的归纳假设与主要任务相匹配

每个测试组合的两个单基因都在训练中出现。Ridge 学习的形式是：

```text
predicted delta(A+B) = intercept + effect(A) + effect(B)
```

它直接在 2,000 维响应空间估计基因效应，L2 正则约束系数。
这与“从已知单基因响应组合到新双基因条件”的任务相匹配。
MLP、Mini-VC 则需要从有限条件中学习更一般的非线性映射；
如果这些额外自由度没有带来足够的预测收益，就可能增加估计难度。

数据虽然有 91,130 个 QC 合格细胞，监督单位却是 pseudobulk。
每折只有 1,568–1,576 个非 control 训练 pseudobulk，来自 196–197 个条件和 8 个 gemgroup。
同一条件的 replicate 不是新的扰动身份。Mini-VC 约有 254 万参数，
并没有 9 万个独立扰动样本来学习复杂的 transition。
参数量与样本数本身不能证明过拟合，但说明表达能力不是唯一瓶颈。

还存在模型选择协议的差别：Ridge 在 validation 上选定 alpha 后，用 train+validation 重拟合；
神经网络只用 train 更新权重，validation 用于 checkpoint 选择。
因此，Ridge 的最终系数额外使用了每折 13 个验证组合。
现有结果没有隔离这部分数据使用差异，不能把全部性能差距都归因于架构。

Ridge 的表现支持“加性近似适合当前预测任务”的解释，
没有证明所有双基因作用都是加性的，也没有单独量化非加性互作的学习效果。

## 3. Mini-VC 多了一层压缩和重建任务

Ridge 和 MLP 预测 delta 后直接加回 reference。
Mini-VC 则把 reference 从 2,000 维压到 128 维，在 latent space 中更新，再解码完整表达。
没有扰动时它输出的也是 reference 重建，因此仍可能存在重建误差。
这条路径需要同时处理基础表达、扰动更新和解码，而不是只估计响应。

损失中还包含权重为 0.2 的 reconstruction 和 0.1 的 latent alignment。
这些辅助目标可能帮助表示学习，也可能与少数强响应基因的精确预测发生取舍。
双基因 embedding 求和只保证顺序不变；经过非线性 transition 后，
并不保证两个单基因响应在输出空间相加。

保存预测提供了一个可以核对的现象：先对各条件的 delta 在基因维度去均值，
再计算预测向量与真实向量的长度比，Ridge 的条件平均为 0.9490，Mini-VC 为 0.8998。
Mini-VC 的预测响应在这个统计量上幅度更小，与整体误差和强响应指标之间的取舍相容。
但 MLP 的长度比更小（0.8676），Pearson 却高于 Mini-VC，
所以“幅度收缩”不是相关性下降的充分解释。Pearson 本身对正比例缩放不敏感。

128 维瓶颈、解码误差和辅助损失都是可能的贡献因素。
实验没有分别移除 reconstruction/alignment，也没有比较不同 latent dimension，
因此无法给出各因素的因果贡献。

## 4. 训练目标与汇报指标有差别

模型训练和 checkpoint 选择主要优化 pseudobulk 的全基因 MSE。
汇报则对条件质心计算响应 Pearson、Top-k recovery，再进行宏平均。
MSE 关心绝对幅度误差，Pearson 关心向量形状，Top-k recovery 关心基因排序；
它们的最优模型不必相同。

| Fold | MLP 最佳 validation MSE | Mini-VC 最佳 validation response MSE |
|---|---:|---:|
| 0 | 0.005536 | 0.005243 |
| 1 | 0.009703 | 0.009299 |
| 2 | 0.005519 | 0.005298 |
| 3 | 0.004718 | 0.004057 |
| 4 | 0.007392 | 0.006840 |

Mini-VC 在五折上按预先设定的验证目标都优于 MLP，
但没有获得更高的测试宏平均响应 Pearson。这使“网络完全没有学到东西”不符合现有证据，
也说明按一个指标选择模型，不能保证其他指标同时更好。

日志中训练误差通常低于验证误差，但两者来自不同扰动条件，
而且训练日志是在 dropout 开启、参数持续更新的过程中累计，验证是在 eval 模式下计算。
因此这里不直接用 train/validation 差距判定过拟合。
训练信息见 [training_summary.csv](../results/model_diagnostics/training_summary.csv)。

## 5. scGPT 的预训练信息只经过了有限的迁移路径

这次模型使用 whole-human checkpoint。官方说明其预训练数据为正常人类细胞，
而本项目处理 K562 肿瘤细胞系中的 CRISPRa 平均响应。
数据背景和预测任务不同，预训练表示能否带来收益需要在下游验证。
预训练基因表示也不等同于已学会“激活某基因后，K562 的其他基因如何响应”。
模型出处见 [scGPT 官方说明](https://github.com/bowang-lab/scGPT) 和
[scGPT 论文](https://www.nature.com/articles/s41592-024-02201-0)。

本项目的 Transformer 编码的是 control cells，不接收扰动后的 target，
扰动身份在编码后以基因 token embedding 经 adapter 加入新预测头。
每个 train/gemgroup 只编码固定的 4 个 control cells，并在基因和细胞维度平均为 context。
一个训练划分只有 8 个这样的 context，它们在同批次的不同扰动条件间共享。
这些 context 可以提供状态信息，但不能单独提供该条件的扰动效应。
新建的预测头仍要从本项目有限的监督条件中学习响应。

每个 control cell 只输入 512 个基因，且表达经过分箱与 pooling。
这限制了预训练分支所保留的细节，是一种可能的信息瓶颈。
不过预测头另有完整的 2,000 维 reference 输入，
所以不能把它描述成“整个模型只看到了 512 个基因”。

更关键的是：微调只解冻 12 层 Transformer 的最后两层，基因 token encoder 仍冻结。
扰动 adapter 和预测头在两组中都训练，但扰动基因的预训练 embedding 没有直接更新。
微调主要调整 control context 的编码，没有把扰动身份送入 Transformer 联合建模。
这限定了本实验中“微调”的作用范围，可能解释它为什么没有带来明显增益。

微调相对冻结的 Pearson 增益只有 +0.000116，已有配对区间跨过零。
预测响应的平均长度比则为冻结 0.9646、微调 0.9547，
没有表现出与 Mini-VC 相同程度的幅度收缩。因此不宜用同一个“预测过于平滑”的解释概括两者。
没有测试其他解冻范围、输入预算或预测头，这些架构原因仍属于解释，尚不是消融结论。

## 6. 缺失 token 和实现故障不足以解释主要差距

105 个扰动基因只有 3 个缺失预训练 token，131 个测试组合中只有 2 个涉及这些基因。
已有五折报告排除它们后，微调 scGPT − MLP 的 Pearson 仍为 −0.009776。
OOV 是局限，但不足以解释主要差距。

已有检查确认编码器 153/153 个参数张量载入，fold0 两组 adapter 重载后与保存预测一致。
本次诊断还核对了五折各模型的 sample ID、真实表达和 reference 一致，结果均为有限值。
这些检查减少了权重未加载、预测错位等简单故障的可能，不能排除所有建模或实现问题。

## 7. 放在已有研究中的位置

Ahlmann-Eltze、Huber 和 Anders 的比较研究也报告过线性和加性基线在扰动预测中的竞争力，
并讨论了基因表示和扰动数据预训练的作用。
这为认真比较 Ridge 提供背景，不是本项目性能差距的直接证据。
其数据处理、训练协议和指标与本项目不同，不能合并分数或视为本项目的独立复现。
见 [Nature Methods 原始研究](https://doi.org/10.1038/s41592-025-02772-6)。

本项目能支持的结论是：在这套 K562 pseudobulk、已见组成基因的组合测试和固定训练配置下，
Ridge 的响应相关性占优。Mini-VC 用更低的整体 MSE 换来了不同的强响应预测表现；
scGPT 的有限迁移路径没有提供足够收益来超过该基线。
现有分析不能确定各因素的因果权重，也不能推断深度模型或预训练在其他任务上无效。
项目不再开展新的消融实验，上述不确定性作为结果解释的边界保留。
